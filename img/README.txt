Headshots go here.

Expected filenames (referenced by index.html):
  img/andrew-vu.jpg
  img/ben-lavie.jpg

If a file is missing the page falls back to initials automatically - nothing breaks.

Specs:
  - Square crop. 600x600px is plenty; anything above 1000x1000 is wasted bytes.
  - Face centred, shoulders in frame. The slot is a circle, so leave a little
    margin - a tight crop loses the top of the head.
  - Keep each file under ~300KB. Larger files slow the page for no visible gain.
  - .jpg as named above. For .png, change the extension in index.html to match.

Only use photos the subject has agreed to publish. These pages are public.
